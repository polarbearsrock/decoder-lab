What the exact reference computes

For each correction class, minimize |Cᵢ| subject to HXcᵢ = s and |Cᵢ ∩ X̄| mod 2 = bᵢ. The two parities differ by one. A row-by-row dynamic program enumerates every allowed horizontal assignment while tracking the vertical frontier and logical parity. It retains one minimum-weight witness and counts all minimum-weight corrections in each class.

This is an exact reference for this finite, unit-weight graph, implemented without Blossom. It is not maximum-likelihood class decoding, which would sum probabilities over every error in a class. The “success” labels use E after the solve, only as simulation ground truth. Tied witnesses use a fixed traversal order.

Exact weight spectrum and probability calculation

For class b, Ab,k is the number of syndrome-compatible errors of weight k. The class mass is Mb(p) = Σk Ab,k pk(1 − p)41−k, and P(b | s, p) = Mb / (M₀ + M₁). Each class contains exactly 2²⁰ = 1,048,576 distinct errors. A row-frontier calculation counts every weight; it does not truncate to the minima.

These posteriors are exact for the assumed independent-Z, perfect-syndrome model. They are not calibrated confidence for circuit noise, correlated faults, or a fixed-weight sampler. A probability describes uncertainty before E is revealed; the displayed shot’s success or failure is a separate, definite fact.

Sampling and reproducibility details

Independent sampling draws one Bernoulli(p) Z error per data qubit. Fixed-weight sampling selects a subset without replacement; it conditions the weight and is not an independent noise model. The deterministic 32-bit generator uses state ← (1664525 · state + 1013904223) mod 2³². Fixed-weight samples use a Fisher–Yates shuffle in descending qubit order.

These experiments model a single perfect-syndrome round. They contain no measurement faults, circuit propagation, temporal correlations, or X/Y errors. Curated examples are selected to illustrate mechanisms and cannot establish comparative decoder error rates.

Why a cleared syndrome is not enough

Once HX(e ⊕ c) = 0, the remaining Z operator is either a stabilizer or a logical Z times a stabilizer. The syndrome cannot distinguish those two classes. Successful recovery requires CE ∈ 𝒮, where 𝒮 is the stabilizer group.

A nontrivial Z̄ changes the relative phase of an arbitrary encoded state: α|0L⟩ + β|1L⟩ → α|0L⟩ − β|1L⟩. It does not flip the logical computational-basis bit.

Geometry, boundaries, and model limits

This is an unrotated distance-5 planar CSS code. Its 41 data qubits lie on edges. The 20 measured X checks sit at non-boundary vertices; the 20 Z stabilizers surround faces. Boundary faces have weight 3. The left and right boundaries are rough, allowing Z chains to terminate without a measured endpoint.

The example uses only Pauli Z errors, perfect syndrome extraction, uniform unit-cost UF growth, and deterministic BFS, reverse-BFS, or DFS peeling forests. It models one recovery round, without measurement errors, circuit faults, correlations, or time. Outcomes here are exact for the displayed error pattern, not a measured logical error rate.

Both check matrices have rank 20 and HXHZT = 0, leaving 41 − 20 − 20 = 1 logical qubit. The displayed Z̄ and X̄ overlap on one data qubit and anticommute.

Is the physical correction actually applied?

The display treats C as a Pauli operator for bookkeeping. A controller can instead track C in a Pauli frame and interpret later operations or measurements accordingly. The logical success criterion is still whether the tracked correction and actual error differ by a stabilizer.

In a real run, the decoder does not know E and cannot use this simulation’s logical verdict. Memory experiments use suitable logical preparation and final readout to assess outcomes; syndrome checks alone do not reveal an arbitrary encoded state.
