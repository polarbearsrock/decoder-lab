Why this matters for hierarchical decoding

A high-confidence bit can belong to a wrong logical correction. A valid OSD candidate can also be in the wrong class. A shortlist score difference is not automatically a calibrated logical error probability or a complementary matching gap.

For an outer decoder, evaluate confidence against logical failures on held-out data. Useful research directions include class-aware candidate aggregation, inexpensive failure predictors, and an escalation policy. Their accuracy and cost need to be measured for the actual code and noise model.

01
The problem

Infer an error from parity information.

For independent binary error variables eᵥ, a parity-check matrix H defines which variables meet each check. You observe s = He over GF(2). The decoder sees H, s, and the channel probabilities pᵥ. It must return an estimate ê; the physical error e is hidden.

P(e|s)∝[He=s]·∏vpvev(1−pv)1−ev

The bracket is 1 only for a syndrome-consistent error. BP approximates single-bit marginals of this distribution by exchanging messages on its Tanner graph. Taking the most likely value of every bit independently can produce a vector that violates a parity constraint.

What exactly is in this teaching code?

Homogeneous code constraints [H | 0]; the first seven columns are H.

H is both HZ and HX for the [[7,1,3]] Steane CSS code; HHᵀ = 0 mod 2. We infer X errors from Z-check outcomes. The three rows generate X stabilizers as well. The all-ones vector represents a logical Z test: for a zero-syndrome X residual, odd parity identifies the nontrivial logical X class.

These graph edges mean “this check touches this variable.” They are not error-chain edges of a surface-code matching graph. Qubits are the circles here.

02
Belief propagation

Each message excludes its recipient’s contribution.

Start with a log-likelihood ratio

λv=ln(1−pvpv)qv→c(0)=λv

A positive LLR favors no error. A negative LLR favors an error. Zero means equal odds. An LLR is a log odds ratio, not a probability.

Check → variable: enforce the observed parity

rc→v(t)=2atanh((−1)sc∏u∈N(c)∖{v}tanh(qu→c(t−1)2))

To advise v, check c asks what parity its other variables are likely to have. If that parity differs from s꜀, v should be 1. The syndrome bit changes the sign. Uncertainty in any of the other variables reduces the message magnitude.

Combine evidence, then form the next outgoing message

Lv(t)=λv+∑c∈N(v)rc→v(t)qv→c(t)=Lv(t)−rc→v(t)Pv(error)=11+exp(Lv(t))e^v=[Lv(t)<0]

The displayed outgoing-message equation gives the raw update. With damping enabled, the sent message is (1 − α) times this raw update plus α times the previous outgoing message.

The outgoing message omits the recipient’s incoming message. Otherwise the check would immediately receive its own evidence back. On a tree, this exclusion supports exact inference after sufficient propagation. On a graph with cycles, information can still return by a longer path, so the independence approximation can break down.

The stopping test is a parity test

residual=s⊕He^stop if residual = 0

The measured syndrome s stays fixed. The residual changes as ê changes. “Converged” in this lab means a syndrome-consistent hard estimate was found; it does not mean that the posterior is exact or that the logical recovery succeeded.

What does message damping change?

The setting α retains a fraction of the previous variable-to-check message: qnew = (1 − α) qraw + α qprevious. Here qraw is the extrinsic sum λ + Σr that excludes the receiving check. α = 0 recovers the original algorithm. Damping affects the next check update; the current posterior L = λ + Σr is not mixed. Damping can change the trajectory and stopping iteration, but does not guarantee convergence or correct logical recovery.

Numerical and scheduling choices

This lab uses natural logarithms, floating-point sum-product updates, and a flooding schedule: all check messages in iteration t use variable messages from t−1. It clips atanh arguments to avoid infinity and maps a zero LLR to bit 0. A half-step exposes one message phase; posterior bars change only after a full variable update. The initial hard estimate is also checked.

Optional variable-message damping retains a fraction α of the previous outgoing message; α = 0 disables it. No normalized min-sum, serial schedule, or X/Z correlation exchange is used. Those choices can change convergence and performance. Production implementations often use other BP variants; this page does not reproduce the Roffe paper’s numerical benchmarks.

03
Ordered statistics decoding

Use the soft ordering to organize an exact linear solve.

  1. Keep BP’s final soft information.Sort columns by P(error) from largest to smallest; break ties by original qubit index.
  2. Build an independent basis B.Greedily retain a column when it raises the binary rank. Stop at r = rank(H). The other n−r columns form F.
  3. Reduce the augmented system.Reorder to [HB HF | s], then perform Gaussian elimination over GF(2). XOR replaces subtraction.
  4. Generate the order-zero candidate.Set eF = 0 and solve the basis variables. A physically valid syndrome guarantees a solution in the basis span.
  5. Explore extra free assignments.For each chosen f, solve eB = b ⊕ Af. Undo the column permutation before interpreting the error.
  6. Score and select.Use the original independent channel likelihood and return the lowest-cost generated candidate. Resolve ties deterministically.
Ncandidates(t)=∑j=0min(t,n−r)(n−rj)

For this code n−r = 4. Orders 0, 1, 2, 3, 4 produce 1, 5, 11, 15, 16 candidates. Searching all sixteen gives the most likely individual error for this sector; it still need not maximize a quantum logical-class probability.

Why can’t I just choose the top r probabilities?

The corresponding columns might be linearly dependent, leaving some syndromes unreachable. The greedy rank test skips dependent columns. In redundant check matrices, r can be less than the row count m. Use independent equations (or consistent elimination with redundant rows), rather than trying to invert a singular m×m matrix.

Why do descriptions of OSD ordering sometimes disagree?

This page uses the probability-ordered syndrome construction described by Roffe et al.: likely error columns form the solve basis and the free bits start at zero. Other formulations build around a BP hard estimate, select by absolute LLR reliability, and search flips relative to that estimate. “Most reliable basis” and “least reliable basis” can refer to different matrix representations. Always state the ordering, the fixed variables, and the candidate-generation rule together.

Is this the same as osd_cs order in the ldpc package?

No. Here t is a Hamming-weight bound over every free coordinate. The combination-sweep method includes all single-coordinate choices and a restricted set of pairs; its order parameter controls that pair search. Exhaustive variants can instead enumerate all assignments within a selected subset. Equal parameter values do not imply equal candidate counts.

04
The quantum complication

A decoder chooses a recovery class.

δ=e⊕e^HZδ≠0⇒syndrome mismatchδ∈rowspace(HX)⇒equivalent recoveryδ∈ker(HZ)∖rowspace(HX)⇒logical X failure

Degeneracy means that many distinct errors act identically on the code space. Ordinary BP’s bitwise decisions can be incompatible with any one of these correlated patterns. OSD constructs globally consistent candidates, but does not automatically sum the probability of every error in each stabilizer class.

A nonzero residual need not be a failure: it can be a stabilizer. Conversely, zero measured syndrome does not rule out a logical error. The third tab makes both distinctions visible using exact enumeration.

How does this relate to surface codes and UF?

The same binary inference formulation can be applied to a surface-code check matrix, or to a detector–fault matrix when the model is expressed in binary fault variables. Surface-code degeneracy and short cycles remain relevant. BP+OSD’s applicability does not establish a speed or accuracy advantage over matching or UF.

For an L0→UF stack, one possible use of BP is to supply probabilistic guidance for edge weights or cluster-growth priorities. That is a separate algorithmic proposal: this lab uses OSD as its fallback and does not implement BP+UF. Demonstrate any improvement using logical-error rates, calibrated confidence, total work, and latency distributions under the target noise model.

What changes with circuit-level noise?

Repeated noisy measurements require a spacetime model. A variable may represent a circuit fault, and one fault can trigger several detectors. Correlated Pauli components and mutually exclusive faults may violate a naive independent-binary model. The seven-qubit, perfect-measurement experiment here deliberately isolates the BP and OSD mechanics.

What can I send to a higher-level decoder?

Final bit LLRs, OSD candidate costs, a best-vs-runner-up difference, and an exact logical probability are different objects. To obtain logical confidence, compare relevant logical classes and calibrate the result. A shortlist can omit substantial probability mass; an arbitrary candidate gap is not a complementary matching gap.
